# Iris Flower Classification (KNN)

This project uses **K-Nearest Neighbors (KNN)** to classify iris flowers into three species: *setosa*, *versicolor*, and *virginica*.

---

## Dataset
- **Source:** Iris dataset (150 samples, 5 columns)
- **Features:** Sepal length, sepal width, petal length, petal width  
- **Target:** Species (encoded as numbers)

---

## Steps
1. **EDA:** Checked dataset shape, stats, and correlations  
2. **Visualization:** Scatter plots + heatmap  
3. **Preprocessing:** Encoded labels, train-test split (80/20)  
4. **Model:** KNN classifier with `k=5`  
5. **Evaluation:** Accuracy, confusion matrix, classification report
